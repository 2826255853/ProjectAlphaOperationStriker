## 目标与边界

新增独立的天花板陷阱安装类别与菜单分类。天花板陷阱和墙面、地面陷阱之间不进行占位冲突检查，同类别仍禁止重复占用。

MapForge 支持一键创建“天花板实体＋安装网格”，也支持给已有板块底面添加网格。玩家在游戏内购买并放置陷阱。

首版包含可放置的灰盒示例，用于验证完整流程；具体攻击陷阱后续单独设计。

## 实施步骤

### 1. 安装类别与配置契约

- 在 `TrapMountType` 末尾新增 `Ceiling = 2`，保留 Ground、Wall 的序列化值。
- 陷阱定义和网格必须同类匹配；Ceiling 与 `WalkableFloorTrap` 不能同时启用。
- 统一提供“地面／墙面／天花板”名称及类型不匹配提示，替换现有二选一判断。
- 继续使用 `TrapDefinition` 保存价格、预制体、占格和实体安装包围盒，不新增平行配置体系。

最小产物：可配置 Ceiling 定义与网格。验收：编译通过，三类匹配及旧值兼容测试通过。

### 2. 天花板网格与放置判定

- 扩展 `TrapPlacementGrid` 的表面几何能力：Ceiling 使用本地 X/Y 平面，本地 +Z 为朝下安装法线；陷阱根跟随网格旋转，再应用定义的轴向修正。
- 坐标转换、格心、射线平面、尺寸、预览和实例创建使用同一套表面计算，保留地面原有坐标语义。
- 天花板必须绑定有效支撑 Collider；沿安装法线反方向检测每格中心及内缩四角，缺少支撑或法线不符的格子禁止放置。
- 延续现有按 `MountType` 隔离占用的机制，覆盖同网格、跨网格 footprint 和实体包围盒检查。Ceiling 与 Ground、Wall 双向互不阻挡；Ceiling 同类重叠仍拒绝。
- 保留玩家、普通实体及怪物道路净空检查。净空只使用陷阱实体安装体积，攻击范围和特效不参与。
- 首版支持水平底面；倾斜、弯曲、动态支撑及负缩放不开放创建，并显示原因。

最小产物：测试场景中可在天花板网格放置灰盒。验收：坐标往返、支撑检测、占用隔离与净空用例通过。

### 3. MapForge 快速创建与 Unity 导入

- 在 MapForge 增加“天花板”创建入口，默认生成静态、有碰撞的板块：宽深 4×4 米、厚 0.2 米、底面高度 4 米；参数可修改，默认格距 1 米、表面偏移 0.01 米。
- 增加“为选中板块底面添加天花板网格”，首版针对水平盒体；重复操作更新已有网格，支持撤销、重做和删除。
- 编辑器显示朝下网格、法线及开放格，并提供尺寸、格距和开关格编辑。
- 在对象的 Unity 映射中新增 `unity.ceilingTrapGrids`，沿用墙面网格的最小字段：稳定 ID、局部原点、旋转、行列数、格距、偏移和开放格数组。
- 同步补齐前端保存规范化、服务端校验、JSON Schema 和 Unity DTO。旧地图缺少该字段时视为空；保留现有地图版本及同步信封协议。
- Unity 根据对象 ID＋网格 ID 创建或更新专用标记与网格，并绑定实际几何 Collider；删除映射时清理对应生成对象。
- 全量导入与 Send to Unity 使用同一生成逻辑。移动、旋转、缩放板块后更新网格世界尺寸与支撑关系，不重复生成。

最小产物：MapForge 创建后，导出导入和增量同步均能得到正确天花板网格。验收：保存重载、重复同步、变换更新及删除均通过。

### 4. 玩家交互、菜单与示例资源

- 天花板瞄准采用有限表面、正面可见和最近命中原则；被挡住的天花板不可穿透选取，关闭或已占用格仍显示具体失败原因。
- 菜单增加“全部／地面／墙面／天花板”筛选及类型标签，保留快捷槽、价格提示和菜单视角锁定行为。
- 天花板预览与最终实例的位置、朝向和尺寸一致；购买、出售及血条复用现有服务。
- 通过 Authoring 生成明确标记“测试用”的 Ceiling 灰盒定义和预制体；灰盒沿本地 +Z 向下伸出，配置明确安装包围盒，不附加攻击行为。

最小产物：从菜单选取灰盒，抬头预览、购买、出售形成闭环。验收：操作成功且金额、占用和实例同步更新。

## 测试与完成标准

- **安装与占用：** 三类匹配矩阵；Ceiling 与 Ground、Wall 按两种放置顺序共存；有无 Collider 均覆盖；同类同格及跨网格重叠拒绝。
- **几何与支撑：** 格心和坐标往返、多格 footprint、不同高度、水平旋转、缺失支撑、孔洞、越界及支撑变换。
- **交互与经济：** 抬头选面、遮挡、无效预览、购买失败回滚、出售释放占用、菜单筛选及光标锁定。
- **地图链路：** 快速创建、已有底面添加、撤销重做、JSON 往返、旧地图兼容、全量导入、重复增量同步及删除清理。
- **验证证据：** Unity 编译、受影响 EditMode 测试及真实 Play Mode 放置检查；MapForge 数据测试和浏览器操作检查；保留编辑器网格与游戏内预览图。测试以结果文件为准，不仅看进程退出码。
