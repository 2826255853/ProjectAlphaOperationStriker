# 陷阱放置模式：投影枪 Plan

## 目标

在陷阱放置模式下，限制玩家只能使用一把“手枪形状的投影枪”：

- 左键继续执行现有的陷阱放置流程。
- 右键只预留输入接口，暂不绑定具体功能。
- 暂不绑定手部骨骼动画；投影枪先以独立的第一人称模型挂点显示。
- 离开陷阱放置模式后恢复玩家原有武器与射击行为。

## 分步实施

### 1. 先固定放置模式状态边界

1. 以 TrapSelectionMenu.CursorOwned / 现有陷阱菜单状态作为放置模式入口，避免新建第二套菜单状态。
2. 在 TrapPlacementController 中增加只读的放置模式状态查询，明确进入、切换陷阱、取消和完成放置的生命周期。
3. 保留当前左键放置调用链，不移动陷阱网格、费用、合法性和购买逻辑。
4. 为右键预留 OnProjectionGunSecondaryAction 或等价的空方法/事件；第一版只消费输入，不改变场景和陷阱状态。

### 2. 接入“放置模式专用武器”抽象

1. 新增 TrapPlacementProjectionGunController，负责放置模式时显示/启用投影枪，非放置模式时隐藏/禁用投影枪，并转发左右键。
2. 在 FirstPersonController 的武器/射击桥接处增加模式判断：放置模式期间禁止普通枪械命中结算，避免左键同时造成伤害和放置陷阱。
3. 不破坏 TrapSelectionMenu 的鼠标锁定逻辑；菜单打开时继续保持视角冻结。
4. 新增最小配置字段，优先通过 Inspector 引用投影枪 Prefab；找不到引用时输出一次明确警告，不自动替换普通武器。

### 3. 分步制作投影枪模型

中间态统一放在：

C:\Users\Origami\Desktop\陷阱素材文件夹\TrapPlacementProjectionGun\

建模步骤：

1. 建立低面数手枪轮廓：枪身、握把、扳机护圈、短投影发射口。
2. 加入投影枪识别元素：发光镜片/投影窗口、简化散热槽、陷阱网格符号面板。
3. 按第一人称观看角度调整比例、握持方向和枪口朝向；不制作手指、手掌或骨骼绑定。
4. 为枪身、投影窗口和发光部件分配可在 Unity 中替换的材质槽。
5. 输出临时 FBX 与预览图到上述素材目录，确认枪口轴向、镜头遮挡和画面占比。
6. 定稿后只把最终模型放入 Assets/Models/TrapPlacementProjectionGun/；中间 FBX、Blender 文件、贴图和预览继续留在桌面素材目录。

### 4. 自动切出投影枪 Prefab

新增编辑器脚本 Assets/Editor/TrapPlacementProjectionGunAuthoring.cs，提供批处理入口：

1. 读取 ProjectSettings/ProjectVersion.txt 对应的 Unity 工程环境，不写死编辑器版本。
2. 从最终 FBX 创建 Assets/Resources/TrapPlacementProjectionGun.prefab，或按项目现有武器引用约定使用等价 Prefab 路径。
3. 自动建立枪口、投影窗口和第一人称挂点层级。
4. 自动移除不需要的物理组件、攻击脚本和手部动画依赖。
5. 为模型设置合适的 Layer、Renderer 材质和本地旋转；暂不创建手部骨骼约束。
6. 生成后执行 Prefab 接线检查，缺少模型或材质时直接报错并停止，不生成半成品引用。

### 5. 第一人称显示与输入接线

1. 在玩家第一人称武器挂点下创建投影枪实例；优先运行时创建，避免直接改主场景大型 YAML。
2. 放置模式进入时只启用投影枪，隐藏/禁用普通武器视觉与普通射击输入。
3. 左键保持调用现有放置动作，不能改成投影枪射击逻辑。
4. 右键接入空事件，未来可扩展为预览确认、吸附切换或其他投影功能。
5. 暂不接 Animator、IK、手部骨骼、握把约束和后坐力动画；为后续接入保留组件挂点与事件接口。

### 6. 验证与验收

代码验证：

- 编译检查 C:\MapEditor\.validation-build\UnityCompile.csproj。
- 增加 EditMode 测试，覆盖放置模式下只允许投影枪、普通射击被禁用、左键仍进入放置、右键只触发预留事件。
- 使用现有陷阱放置/网格验证流程，确认合法性、费用和陷阱实例创建没有变化。

运行验收：

- 进入陷阱放置模式：画面只显示手枪形投影枪。
- 左键：仍能放置陷阱，不产生普通武器伤害。
- 右键：当前无可见副作用，但事件可被日志或测试观察到。
- 退出放置模式：普通武器与普通射击恢复。
- 模型不依赖手部骨骼动画，缺少 KINEMATION 资源时不会新增编译依赖。

## 交付顺序

1. 先提交状态/输入骨架和空的右键接口。
2. 再提交模型制作脚本与投影枪 Prefab 自动生成器。
3. 再提交最终 FBX、Prefab 接线和运行时显示逻辑。
4. 最后补测试、编译检查和第一人称预览图。

## 暂不做

- 不绑定手部骨骼动画、IK、握持姿态或手指动画。
- 不给投影枪增加伤害、弹药、换弹和普通枪械后坐力。
- 不重写陷阱网格、费用、购买或放置合法性系统。
- 不改 MapForge 地图数据；本需求只涉及玩家放置模式与第一人称武器表现。
